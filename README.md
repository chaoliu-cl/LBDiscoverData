# LBDiscoverData

`LBDiscoverData` contains the data-facing components of the original
`LBDiscover` workflow.

## Scope

This package focuses on:

1. Data retrieval from PubMed/NCBI
2. Text preprocessing
3. Biomedical entity extraction and dictionary management

It is intended to be paired with `LBDiscoverAnalysis`, which provides
co-occurrence analysis, discovery models, validation workflows, and
visualization.
